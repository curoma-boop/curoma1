## основы git

### зачем git

#### почему не флешка?
1. Флешка - потенциальный разносчик вирусов
2. Ваши личные данные могут случайно попасть на чужой компьютер
3. Антивирус может удалить ваши файоы с флешки
4. Флешка может поряться или сломаться

#### почему не яндекс или гугл диск?

1. облако яндекс не контралирует версии файлов
1. ваши данные яндекс или гуглмогут случайно остаться на чужом комьпьютере

### преимущества git

1. трудно потерять свои проекты
1. легко отслеживать версии проектов
1. легко делитьсяс другими людьми вашими проектами
1. легко вести совмесную работу на одним проектом
1. git - дефакто стандарт и интегрирован почти во все современные технологии IT
1. гит можно создавать веб страници как на хостинге
1. git - сервисы дают возможность автоматизировать сборки и тесты ваших приложений

`Основные состояния Git-репозитория`
1. **Инициализация** - git status - показывает текущее состояние репозитория
1. **Подготовк** - git add . - подготовка (добавление) изменений
1. **Фиксация** - git commit -m 'Some message'

1. **Синхронизация** - удалённой копией текущего репозитория - `git push` и `git pull`

### Что можно сохрнять в git?

1. Любые текстовые файлы, объёмом <= ~ 40 mb.
1. Изображения, документы, mp3, PDF, короткие видео т.п.
1. Все имена файлов и каталогов только по-английски без пробелов и спец. символова!

### Основные команды Git

Получить версию установленного Git
```shell
git version
```
или
```shell
git --version
```
Получить справку
```shell
git help
```
**Сменить текстовый редактор по умолчанию**
На `Micro` (проще для новичков)
```shell
git config --global core.editor "micro"
```
На `Nano` (чуть сложнее для новичков)
```shell
git config --global core.editor "nano"
```
На `Micro` (элементарен для новичков)
```shell
git config --global core.editor "code --wait"
```
**Представиться системе Git**
Сообщить свой никнэйм
```shell
git config --global user.name "Fixic"
```
Сообщить свой эмэйл
```shell
git config --global user.email "my_email@mail.ru"
```

>**Если вы на чужом компьютере, то вместо `--global` используйте `--local`**

открыть папку клонированного репозитория
```shell

```
Получить статус текущего репозитория
```shell

```
Получить состояние удалённого репозитория
```shell

```
```

```
получить список удаленых меток
```shell
git remote --v
```
получить лог
```shell

```


